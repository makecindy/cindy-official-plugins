# 自动知识纪要（0.4.0 开发版）

已有转录的单集可点击「知识纪要 → 生成知识纪要」。插件会新建 Cindy 任务，
调用 `podcast_minutes`，通过你配置的文本模型整理。会消耗模型用量，不会重新
转录音频；这条流程无需额外的供应商密钥或 MCP。

产出包含概览、核心观点、主题章节、嘉宾明确表达的选择、金句、原文中存在的
链接和完整转录。模型选择已有句子的编号，由程序提取并匹配引句。章节导航范围
根据原文锚点计算，连续覆盖全部转录段落；它用于定位，不代表人工核准的语义
边界或逐句时间戳。

阅读页支持折叠目录、定位原文、完整转录搜索和章节追问。追问会带章节、原文
版本与段落范围新建 Cindy 任务，要求读取并引用原文。这条追问路径已实现，
本次 EP52 实测没有实际提交追问任务。

阅读版去除汉字间识别空格，在句末标点及部分转折停顿处分行；不改写已存原文、
识别事实、说话人身份或时间区间。可展开未整理原文核对。原文匹配不等于音频
或解读准确。关键决策可能是历史选择，不等于本期形成了待办；没有依据的决策
和链接留空。

`podcast_minutes` 的 action：

- `generate`：只处理已有的当前转录；按语言及原文版本复用。
  `regenerate:true` 重新生成，`overview_only:true` 只基于已有章节更新概览和
  核心观点选择。
- `read`：返回元数据、过期状态及产物路径；`section_offset` 每页读取最多两章。
- `export`：经当前 Agent 调用的宿主授权，将独立 HTML 和结构化 JSON 写入
  当前任务工作目录的 `outputs/`。

JSON/HTML 按生成编号保存在插件 Library。只有完整生成并成功写入后才替换
当前结果指针。转录更新后旧纪要标记过期；模型不可用、引用无效或结构不完整
会保留旧结果。旧文件保留，本版不自动清理，也不发布到外部知识库。

暂未实现 YouTube 提取。现在会在联网前明确提示替代输入方式；寻找同一期
RSS 是 Agent 的后续操作，不冒充插件已具备自动匹配能力。
