# 播客洞察

批准范围：[提案 #158](https://github.com/makecindy/cindy-official-plugins/issues/158#issuecomment-6120456702)。首版包含 M1 导入与原文取证，以及可选的 M2 AssemblyAI 云转写；站内回放留到 M3。

从侧边栏打开资料库，导入 RSS、Apple Podcasts、小宇宙或以 `.mp3`、`.m4a`、`.wav`、`.ogg`、`.aac`、`.flac` 结尾的公开音频 URL，再读取与检索已有转录；允许查询参数和片段。页面链接导入会创建可见的 Cindy 任务；在任务卡片中选择 RSS 候选、确认云费用。提供8个 `podcast_*` 工具。可选密钥只由 Cindy 保存，Agent 参数不能提交付费转写。

构建：`node podcast-insights/build.mjs`。测试：`node --test .tests/podcast-insights.test.mjs`。最低要求正式稳定版 / Beta Cindy0.1.103。清单资源覆盖中英日韩；页面和运行时支持中英文，其余回退英文。

SQLite 迁移保留旧版0.1.x JSON、回执、结论与导出原文件，使用稳定 ID 导入原转录版本和未完成云任务。删除只影响新索引并创建备份，旧文件和导出仍保留；卸载保留资料库。

与批准草稿的差异：保留原 `assemblyai_key` 名称，因为宿主没有可用于迁移明文密钥的合法接口，避免要求用户重新配置。密钥末尾仅在宿主状态返回 tail 时显示，不读取完整密钥。页面导入和云预估创建普通可见任务（`agent.tasks`），没有后台 Agent 权限。不确定提交仅核对服务商最近100条任务，遇到歧义保持未知。移除普通 DOCTYPE，拒绝实体声明，防止实体展开。

内容授权、API 权限与用户确认分别判断。公开上线前仍需核对服务商保留 / 训练设置及实际模型数据流；本地资料库不代表分析全程本地。实机验证完成前不勾选验收项。

0.2.1修复：迁移中断后恢复、切换单集清空旧正文与定位、长段文本分割且不编造内部时间、保留带时间段落边界、段落与字符游标配对翻页、GUID去重、ISO日期排序、云失败保留已有转录就绪状态、Host错误正确返回失败，以及工具结果明确标注不可信内容。未知云任务匹配限定提交时间窗。来源网络依赖Host严格在途callId、URL／SSRF／DNS／重定向守门与固定连接地址；插件不授予内网访问。费用卡明确仅发送音频URL及处理选项，未请求零保留或退出训练。

0.2.2修复：检索覆盖来源时间区间相同的相邻文本块，避免人工切口漏检。选中的引用或整段正文超过1200字符时明确提示缩短选择，不保存，不静默截断。

0.2.3修复：引用卡展示命中原句附近的上下文，明确标记省略并保留完整原文的资料库入口，声明来源外链能力。云提交后的本地状态写入失败仍返回未知态与不要重提的提示；遗留 submitting 任务纳入状态对账，重启后也可恢复。

0.2.4修复：引用优先定位直接命中的段落，再检查跨段原句，保留真实说话人、时间和定位ID。未提交预估刷新当前音频与费用，展示后发生变化需再次确认。云提交认领与失败转换原子写入任务及单集状态。episodes用latest:N（1-50）或订阅源GUID选择发布方转录，不使用资料库单集ID。

0.2.5修复：持久 claiming 状态区分付费请求前的认领阶段。认领查询失败仅释放本次认领并恢复原单集及卡片状态；释放写库失败可在状态查询、准备预估或重启时恢复。claiming 恢复不请求服务商，也不提交付费请求。

0.2.5同步修复：来源抓取拒绝托管凭证的AssemblyAI API主机，仅固定云操作可访问。兜底写入保留已知远端ID并报告已执行。资料库检索显示真实节目及单集，清空旧操作目标。空的已完成转录原子落为失败终态。

0.2.6修复：仅Host已完成的4xx响应表示云请求被拒绝，未完成传输保持未知。转录限制为5MB、切分前20000个原始cue。检索不返回内部norm和完整相邻上下文，正文总预算20000字符、单条1000字符并明确标记省略。界面时间按时长格式化，超过24小时不回绕。

0.2.7修复：元数据入库前拒绝超长字段，标题500/作者300/语言64字符，GUID及URL4000、日期128、最多50个转录链接且类型128字符。引用加摘录总预算20000字符，单条原文800字符，带省略标记及reference_index；卡片公开前三条命中限制。query/quote清单上限300/1200字符。资料库仅单集分页，节目前500/任务最新100为带省略标记的快照。来源Accept支持RSS/Atom/HTML/VTT等已声明类型。

0.2.8修复：摘录先定位逐字原句，再回退规范化匹配；20000个源cue切分后可超过20000存储块。明确已知音频4小时/256MiB上限。资料库摘要不返回远程转录、GUID及音频/页面URL，短标题与总60000字节预算限制输出，单集游标按实际返回条数继续。around_segment从目标段开始。笔记独立分页及加载更多，预期错误给出具体处理方式。

0.2.9修复：小宇宙候选确认保留episodes选择。导入回执最多60000字节，含省略计数与资料库继续查询，入库内容保持完整。读取分页不携带内部norm，即使max_chars=1。笔记超过5000字符时明确拒绝保存，不静默截断。 即使尚无转录，也可用资料库include_guid:true及游标读取完整GUID。

0.2.10修复：引用先检查全转录中的逐字命中，再回退规范化或跨段匹配；检索结果将来源元数据计入60000字节总预算；公开音频URL支持文档列出的扩展名及查询参数/片段；错误episodes选择在抓取和写库前拒绝；每个云任务独立计算轮询期限。


0.2.11修复：引用检索不再设置20000行隐藏上限；源cue切分后仍会检查完整活动转录，包括末尾的合法段落。

0.2.12修复：用户确认前的云预估和状态回执不返回完整音频URL；状态检查使用受控并发并限制60000字节总回执。

0.2.13修复：云预估单集改用显式安全字段投影；云任务状态加入offset/limit分页（0.2.15改为键集游标）；发布方转录最多四路受控并发，并在首个来源失败后尝试备用来源。

0.2.14修复：英文清单说明与四语言云任务分页契约保持一致。

0.2.15修复：状态按提交时间/ID用cursor=next_cursor续查，避免终态变化跳过活动任务。本地分页不能扩大服务商最近100条核对范围。发布方转录失败时等待所有抓取结束；共享120秒/100次尝试预算，明确返回未完成单集ID且不将其标为失败。

0.2.16：资料库恢复逐页续查本地任务，每页完成后刷新，并在页间让排队操作执行。恢复页及每轮轮询使用4路并发和共享60秒网络期限，请求超时随剩余时间收缩，全部 worker 结束后才释放队列；存储和卡片发送可能另需时间。未检查的卡片任务优先进入下一轮，每个任务保留29分钟/40次检查上限。读取只返回选定的单集元数据和来源页面链接，不返回音频URL及GUID。缺少资料库/网络API时返回CLIENT_UPGRADE_REQUIRED及升级说明。

0.2.17 补齐无卡片旧任务恢复、连续多段引用和 Unicode 切分回归。读/搜/引用统一来源链接投影；完整引用回执限60000字节，显式返回待续查引用。阅读器跟随活动转录版本变化，无关刷新及翻页失败保留已加载正文。

0.2.18: 完整回执最多60000字节；续读保留完整Unicode字符（max_chars=1时单个补充平面字符可占2个代码单元）。 支持的HTML会单次解码以分号结尾的命名字符引用。 多个未知任务的时间窗口重叠时不猜归属；原子认领远端ID，避免重复占用。

0.2.19: JSON：数组或 {segments:[...]}；text（别名 body），start/end（别名 startTime/endTime）单位为秒，不是毫秒；speaker 可选。HTML 排除注释、嵌套 template 和原始文本容器，不是通用页面可见性/CSS 提取器。

0.2.20：HTML 证据改用固定版本标准解析器 parse5，统一排除 plaintext、raw-text 和 template 上下文，不执行脚本或请求资源。WebVTT 字符引用单次解码；发布方重试保留活动云任务状态；续页遇到转录版本变化从头重读；删除后刷新笔记。进度卡显示本次恢复错误。重启只清理未完成且非活动的用户/发布方版本，保留已完成历史、活动和云版本。解析器来源及许可见 THIRD-PARTY-LICENSES.txt。

0.2.21：界面语言资源初始化失败时，待核对云任务卡仍显示默认恢复指引，不会因提示文案缺失而停止更新。
