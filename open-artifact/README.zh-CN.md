# Open Artifact for Cindy

在有可写工作目录的本机桌面任务里输入 `/artifacts`，描述想做的作品。支持文档、幻灯片、设计稿与设计系统、白板、表格、数据看板及短动画。作品会在任务侧栏打开。同网址再次打开会复用原页签。

可以在页面编辑和导出。主动发送评论或修改请求时，消息会进入作品所属任务的队列。协作者留言和系统通知保留在 Open Artifact 内。作品文件保存在任务工作目录。重启 Cindy 后，可以从原任务重新打开作品。

要接管文件夹或把已有作品移交给另一个任务，在目标任务里调用 `adopt` 并在 Cindy 弹窗确认。移交成功后，新评论和修改请求会发给目标任务。

首次使用时启动随包运行时。无需另装 Node、联网下载运行时或登录外部账号。插件不会自动发布到云端。安装时需要批准本机 Node 工作进程、本机预览和任务投递。停用后工作进程及其启动的后台服务随之停止。

作品目录和工具指定的导入、导出路径必须解析到当前任务工作目录内。页面保持打开时，编辑器沿用作品登记的工作目录。复用已解包的运行时前，插件会按随包清单校验文件。

基于 [Open Artifact](https://github.com/JimLiu/open-artifact) 和 [原 Cindy 接入](https://github.com/makecindy/cindy/pull/12226)。插件随包提供 Open Artifact 官方 0.16.1 运行时，并启用上游的工作目录限制。构建方式见 [vendor/BUILD.md](vendor/BUILD.md)，许可证见 `THIRD-PARTY-LICENSES.txt`。
