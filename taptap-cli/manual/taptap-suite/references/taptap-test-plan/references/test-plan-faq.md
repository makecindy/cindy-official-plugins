# Test Plan FAQ

以下是用户高频提问，agent 应从本文档知识直接回答。

### 数量/配额概念

- **计划人数**：测试计划总上限。
- **已配置发放上限**：所有批次 quota 之和，不能超过计划人数。
- **已领取人数**：实际领到资格的人数。
- **报名人数**：通过招募入口报名的人数，独立于发放，报名不等于获得资格。
- **激活码数量**：独立库存，用户兑换激活码获得资格，兑换后计入已领取人数。

关系：计划人数 ≥ 已配置发放上限 ≥ 已领取人数。报名人数和激活码数量是独立维度。

常见困惑：
- "领取人数没满但不能配新资格"→ 已配置发放上限已达计划人数，需先提高计划人数（update-test-plan）。
- "删了批次名额会退回吗"→ 已发放的不退，未发放的配额释放。

### 时间概念

各层时间嵌套关系（外层约束内层）：

- **测试时间**（最外层）：测试计划 start_time ~ end_time
- **招募时间**：可与测试时间重叠，通常在测试开始前或期间进行
- **批次发放时间**：必须在测试时间范围内
  - 先到先得有效期：批次内的领取窗口
  - 短链有效期：短链可访问的时间段
- **预下载时间**：测试开始前 N 天开放预下载

常见困惑：
- "改了测试时间批次时间跟着变吗"→ 不会自动变，需要手动调整超出范围的批次。
- "批次时间能超过测试结束时间吗"→ 不能，创建/修改时会校验。

### 结束/停止区分

| 操作 | 影响 | 可逆 |
|---|---|---|
| 停止发放 | 暂停某批次新增资格，已有资格用户可继续游玩 | 是 |
| 结束测试 | 整个测试结束，所有用户无法游玩 | 否 |
| 删除批次 | 删除未开始的批次配置，已发放资格不受影响 | 否 |

- 结束后评价和评分保留，但玩家不可再进入游戏。
- 结束后不能按普通修改恢复；用户明确要求重新开启时可用 `update-test-plan(reopen=true)`。CBT 必须提供新的开始和结束时间，并重新通过当前 policy 校验。
- 停止发放后招募不会自动停止，需单独关闭。
- 名额发完后批次自动停止，无需手动操作。

### 概念解释

- **篝火模式**：仅对 CBT 有效。开启后游戏不出现在搜索、推荐和排行榜中，只能通过直接链接访问。开启后立即生效，今日游戏、排行榜等资源位会被下掉。**即使后续关闭篝火模式，资源位不会自动恢复，需要重新申请上架**。适合保密性要求高的测试，但务必提醒用户谨慎开启。
- **"仅有测试资格可登录游戏"**：玩家可以看到游戏页面并下载，但启动游戏时需要测试资格才能进入。
- **删档测试**：测试结束后清除测试期间产生的游戏数据（角色、存档、充值等）。OBT 强制删档。
- **付费测试**：测试期间开放内购。前置条件：游戏已取得版号且已接入防沉迷。
- **先行服/测试服**：正式服已开放下载或试玩后继续开展测试时使用的独立应用。当前 scope 是不是先行服以 `get-test-plan-environment` 的 `type` 为准（`preview`=先行服，`primary`=正式服）；创建后默认为草稿，需要提交审核后生效。
- **预下载**：测试开始前允许玩家提前下载安装包，减少开测当天的下载压力。
- **"CBT 评分不计入正式分"**：封闭测试期间的玩家评分独立于游戏正式评分，测试结束后不影响公开评分。
- **iOS 不支持 OBT**：苹果政策限制，开放式测试只能选 Android 和 Windows 平台。

### 平台与包体

- **OBT 支持哪些平台**：当前只能明确选择 Android、Windows 或两者，不支持 H5。
- **CBT 为什么创建时没有平台**：CBT 的创建请求只定义计划本身；后续资格发放批次有独立的平台输入，但当前公开 schema 没有声明数字值的平台语义。不能自行映射，也不能据此推断 CBT 默认使用 Android。
- **测试计划会自动使用当前资料页包体吗**：当前 CLI 和服务端契约没有返回或保证这种绑定关系，也不能指定包体 ID/H5 版本 ID。不要向用户承诺会使用某个当前包体。
- **H5 怎么测试**：H5 当前走包体管理的自测二维码，不属于 CBT/OBT。先查询 H5 包体列表（`list-h5-packages`）和版本候选，再为用户选定的 H5 版本生成二维码。
- **H5 能否进入 CBT/OBT**：当前不能通过 CLI 契约明确实现。服务端需要补充 H5 平台语义及版本绑定字段或稳定的已绑定槽位语义；仅增加平台名但不能锁定版本仍不足以确认测试目标。
- **如何判断当前游戏没有可用 H5 包**：只能依据本次包体列表、上传解析状态或错误结果；不能根据测试计划接口缺少 H5 字段反推。

### 可见性/通知

- CBT 期间没资格的玩家：能看到游戏页面，显示"测试中"状态，可预约但无法下载/进入。
- 测试期间游戏是否出现在推荐：取决于游戏资料页状态，与测试计划本身无关；篝火模式会隐藏。
- 玩家怎么知道开测：有预约的玩家会收到推送通知；招募页面可被搜索到。
