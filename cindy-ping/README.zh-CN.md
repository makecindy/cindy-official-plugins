# Cindy Ping

戳一下猫，给 Cindy 发个 Ping。你正在看的东西、要交代的事，一起捎过去，Cindy 收到后接着做。当前仅支持 macOS 14+。

支持 **macOS 14+（Apple Silicon 和 Intel）**、**Cindy 0.1.114 及以上**的可配置桌面表情轮盘。按住快捷键、移向表情、松键发送；默认只展示，可自行逐个配置项目、会话或伙伴投递。当前不支持 Windows 和 Linux，无第三方运行依赖。

## 使用

将 `.cindy` 包导入 Cindy，在插件详情页启用 Cindy Ping。设置改动立即生效，无需单独保存。可录制修饰键、普通单键或组合键，默认 `Command + G`。**按下即在鼠标处显示轮盘；按住移动选择，松开快捷键发送并收起轮盘，无需点击或拖拽。** 回到中心、Esc、右键或拉远至圆心240点外取消；盘外容错区保留已选项。与其它按键组成不同组合时取消本次轮盘；普通字母／数字单键绑定仍会占用该字符。

录制时暂停轮盘输入，Esc、失焦或超时取消后恢复；点击「使用此快捷键」立即应用。识别全局快捷键需要辅助功能权限，纯展示也需要此输入权限。插件只检查已有权限，不单独请求系统授权。更新到支持权限复用的 Cindy 后，在 Cindy 中停用并重新启用插件，再刷新状态。

表情最少四个，没有固定数量上限。可用 emoji 或本地 PNG/JPEG/GIF/WebP；点击轮盘配置、拖动排序，选中扇区内直接 Pin/删除。Pin 保留该表情的绝对角度，中心 ＋ 跟随鼠标选择插入位置。图片引用原文件，请保留；动态图使用 macOS 解码的图像帧，不保证播放动画。**每次表情立即展示，互不替换；只有绑定行为等最后一次触发满 2 秒。** 界面跟随 Cindy 语言，日语和韩语设置按契约回退英文。

可选行为：

- **只展示表情**：不取材、不截图、不调用模型、不创建任务、不发消息，同时丢弃此前待执行的行为。
- **新建任务**：每个表情独立选择项目、模型、推理强度及可用的 Fast；模型缺省时沿用 Cindy 为插件保存的默认配置，任务权限仍由 Cindy 管理。
- **补充信息**：选择本机可用的普通任务，向其中发送指令与窗口材料；接收方的模型、工作目录和权限保持不变。
- **发给伙伴**：选择本机活跃伙伴，由 Cindy 投递到其对应任务，保留伙伴自身配置。

点击轮盘中的表情，在右侧分别配置行为、任务、模型和指令，改动立即生效。模型选择器支持搜索，按供应商分组并显示来源图标，可筛选 Claude Code、Codex 或 Pi；推理强度和 Fast 在同一处调整。默认收起隐藏模型，当前正在使用的隐藏模型仍保留可见，重复选择当前模型保留有效的调参设置；失效参数可通过重选恢复默认。模型选项来自 Cindy 当前可用目录，区分框架和供应商；失效配置会保留并提示重新选择，不静默切换模型。单表情模型配置需要客户端 `tasks.models` / `setModel` 能力，未配置覆盖的旧表情继续沿用原有行为。

配置只保留「只展示」「发送到…」两个入口。只展示同时取消上一个尚未生效的动作（2秒内），以短提示说明；不回滚已经完成的副作用。轮盘最少四项，达到下限时点击删除会提示原因，超过四项可直接删除。发送到下拉菜单提供最近活跃的三个会话／伙伴、每次选择会话／伙伴、指定会话／伙伴，以及在所选或指定项目中新建会话。固定目标直接在 Cindy 插件设置面板内展开列表，可选筛选名称或目录，不另开原生窗口；只保存稳定的 `{kind,id}`，每次触发复核，失效不会改投。

每次选择和最近模式在选中表情时直接显示最多三个二级选项；完整列表可滚动翻页。候选按 Cindy 返回的活动顺序，在每次唤出时查询并冻结，不在当前轮盘重排，不自动选人。固定项和本地操作不展开。目标尚未返回、未选二级目标或列表为空时松键不投递。轮盘约228点、一级仅显示表情，圆心保持唤出时鼠标位置。

任务和伙伴还可以逐表情配置「排队发送」或「立即插话」，缺省排队；插话不停止当前工作，暂不可用时由 Cindy 排队，并显示实际接受方式。筛查拒绝不转队列重试，结果未知则暂停并要求检查，不换请求键重发。新建任务始终走队列。旧配置没有 target 时继续原有自有任务和显式模型逻辑；主动选择新目标方式后才改用新入口。

清单同时声明 `agent.tasks:true` 和独立的 `agent.targets:true`，目标访问由 Cindy 独立校验，不能仅凭原有自有任务能力访问其他目标。声明 `showTaskPreferences:false` 隐藏重复的宿主卡片，单表情模型在轮盘右侧配置；任务能力、已有默认值和权限检查仍由 Cindy 保持。

新安装默认四项为「解困、求证、找灵感、撤销」：四个都只展示，撤销保留独立的 Cindy 黑猫图案；每个只展示表情都可取消上一条待执行动作。旧 undo 行为自动归为只展示，图案、名称和位置保持。表情库提供十一张黑猫图片，不再包含指令模板；新增内置／自定义表情均默认只展示，切换行为也不自动填写指令。需要任务行为时由用户自己填写。更换图案保留已有设置。更新时把未自定义的旧工厂指令改为只展示，并将原默认第四格改为撤销，保留快捷键和位置；用户自写指令、固定目标、显式模型和自定义轮盘保持。

每次触发先即时弹出猫头，约 460ms 内回弹，并在落点扩散双层涟漪；2 秒后淡出，系统减少动态效果设置下跳过回弹与涟漪。任务行为仍在最后一次操作 2 秒后开始，可能产生模型费用。拒绝任务权限后仍可将行为改为只展示。

## 取材与取消

最后一次触发满 2 秒且目标已选定后，先收起插件选择器，再读取有限的辅助功能文本并按配置截取原目标窗口；取得的是延迟后的画面，不是触发瞬间的历史截图。表情显示后才识别原目标窗口，截图用 ScreenCaptureKit 精确选中该窗口，排除表情和轮盘。窗口关闭则报告缺项，不切到别的应用或改截整个桌面。选区必须属于同一窗口，附近文本数量受限，不承诺获取完整浏览器正文。

不读剪贴板、不持续录屏。设置页只读检查系统权限，未检查与未授权分开显示。客户端 #6029 将 macOS Node worker 的 `disclaim` 改为 `false`，使子进程可沿 Cindy 的系统权限归属运行；插件保持 worker 直接启动原生 helper 的链路。插件不再提供单独授权按钮，也不包含原生权限请求调用；缺权时报告具体能力，不自动申请授权。是否实际可用仍以包含该改动的安装版运行结果为准，不能用单独编译 helper 的结果代替。纯展示不读取窗口内容。辅助功能读取跳过密码控件，但截图仍包含目标窗口实际显示的内容。文本和图片可以分别缺失，原因记入材料。

截图通过 `attachments:[{base64,name}]` 进入 Cindy 既有媒体链路，作为消息图片展示并进入模型输入；窗口文字、来源、落点、采集时间和缺项直接进入正文。不创建取材目录、context.json 或临时截图路径，不把屏幕内容写入插件 KV 或日志。使用前检查 messageAttachments 图片能力，缺失时停止投递，不静默丢图，也不回退文件路径。

所有表情共用一个「最后一次」记录；新触发取消旧计时，迟到的采集结果直接丢弃。旧自有任务输入按自身 `runId` 精确取消，新目标按 requestKey 只撤回本次尚未执行的输入；新 Ping 还会关闭旧选择器，迟到的选择和取材回调均丢弃；不会停止整条任务或用户的其他输入。已完成的副作用无法撤销。取消或投递结果不明时暂停自动投递，在 Cindy 检查后手动恢复，不自动重发，也不用新请求编号绕过去。重启不会重放旧操作。

## 开发和打包

JavaScript 与 `node/*.cjs` 均为本插件直接维护的源代码，不是第三方 vendor 或打包生成物；不内嵌第三方运行库。

macOS 上安装 Xcode Command Line Tools 后运行 `node scripts/build.mjs`，编译 macOS 14+ 双架构程序并本地 ad-hoc 签名。随包程序采用 ad-hoc 签名，未单独公证；由 Cindy Node worker 直接启动，不另开独立应用。源码在 `native/EmoteHelper.swift`；安装包运行时不要求另装 Swift 或 Node。

`npm run check` 检查 JavaScript 语法；`node scripts/stage.mjs` 将运行文件收集到 `build/package`，再对该目录调用 Cindy `ghost_forge_pack`。打包不安装、不发布。

Worker 输入关闭、插件停用或 Cindy 退出时，原生程序与快捷键一起退出。在 Cindy 停用插件后释放输入监听，保留配置。官方仓打包提交的插件目录，并附上仓库根目录的许可证和商标说明。

参考：[Cindy](https://github.com/makecindy/cindy)、[ScreenCaptureKit 窗口过滤](https://developer.apple.com/documentation/screencapturekit/sccontentfilter/init(desktopindependentwindow:))。[lolPing](https://github.com/darrenprx/lolPing) 仅提供交互灵感，没有复制代码或英雄联盟素材。

在仓库根目录运行 `node --test .tests/cindy-ping.test.mjs`，覆盖调度、配置和投递的隔离回归检查，不启动 Cindy、不发送真实消息。原生编译与模拟检查不能代替实机验收。

图标与十一张黑猫表情是为本插件生成的原创插画，不内嵌 emoji 字体或复制游戏素材。表情使用原始 1254 × 1254 分辨率的无损 WebP，解码后全部 RGBA 像素与原 PNG 一致。原有内置 PNG 引用自动对应到同图 WebP，不改变指令或目标；自定义图片路径不变。图片由 Cindy 和 macOS 解码，不内嵌额外解码库。

## Agent 配置

插件不声明 `command`，不提供独立对话入口；Agent 仍可在普通对话中发现并配置插件。Agent 可调用 `get_config` 读取完整配置和 revision，用 `list_targets`／`list_models` 查询准确目标及模型，修改用户要求的字段后通过 `configure({revision, config})` 保存。保存与设置界面共用校验、revision 和串行队列，旧页面不能覆盖 Agent 的新配置，不直接发表情、取材或投递任务；配置已变化时返回 `STALE_REVISION`，重新读取后再改。支持逐表情动作、目标、图片、指令、模型、插话／排队、角度和 Pin，以及快捷键；保留未要求改变的字段。新增项应默认只展示、prompt为空，至少四项，Pin 角度不重排。
