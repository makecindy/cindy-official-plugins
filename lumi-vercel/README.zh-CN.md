# Vercel · Lumi 插件

在对话里查询和管理 Vercel 项目、部署、构建日志、域名和环境变量。提供连接设置页，无常驻看板。运行时支持 Lumi 桥接，并兼容对应的 Cindy 桥接名称。要求 Lumi 0.1.131 或以上。

## 连接

1. 在 Lumi「插件」中导入 `lumi-vercel-1.0.0.lumi`。
2. 打开插件设置，点击「到 Vercel 创建令牌」，为需要管理的账号或团队创建访问令牌。
3. 在设置页粘贴并保存令牌，然后测试连接。不要把令牌发进聊天。
4. 可选填写默认团队 ID 和项目名称。团队留空使用个人账号；修改操作仍需明确指定项目。

令牌由 Lumi 保险库保管，只注入 `api.vercel.com` 请求，不会交给 AI、写入插件参数或广播通道。GitHub 登录不等于 Vercel 授权。

可以直接说：「查最新部署」「看构建日志」「重新部署这个版本」「把 main 部署到预览环境」「列出环境变量的名字和目标环境」「给这个项目绑定域名」。修改操作会先展示目标和影响，再通过 Lumi 原生确认框执行。

## 数据与限制

- 工具结果不会返回环境变量值。加密值或敏感值通过 `value_file` 从当前任务目录的 UTF-8 纯值文件读取，再直接发送给 Vercel。文件路径不能隐藏或越出任务目录；内容包含末尾换行时也会原样发送，文件会留在原处。公开的普通值可直接使用 `value`。
- 更新环境变量后，用 `deploy_git` 发起新构建以使用当前项目配置。现有部署不会因此改变；`redeploy` 保留来源部署的目标环境。
- 支持 production、preview 和 development；支持预览分支变量，暂不支持自定义环境。
- 支持已有 GitHub/GitLab 仓库部署；不上传本机源码、不安装 CLI。
- 绑定域名不会购买域名或修改 DNS。解绑可能中断访问。
- 部署已提交、构建 READY、正式流量已切换，是不同状态。工具会分别返回相关事实。
- 日志最多读取 500 条、24,000 字符，会遮盖常见凭据格式；应用自己输出的私密信息仍可能出现在日志里。
- 不会自动重试写操作。超时或服务端错误后，应先核对 Vercel 实际状态。
- 本版不包含删除项目/部署、域名购买、提升正式部署和回滚。

源码包含基于真实插件代码的模拟 Host 测试。当前构建的准确源码未能从 GitHub 获取，使用随附接口契约并通过 Forge 校验；真实账号的端到端验证仍需安装并连接 Vercel 令牌。打包不代表已经安装、连接账号或上架。
