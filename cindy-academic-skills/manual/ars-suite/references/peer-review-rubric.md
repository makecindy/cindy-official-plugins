# 多视角同行评审、方法学效度审查与国际报告规范指南

本指南为 Cindy 智能体提供模拟国际顶刊双盲同行评审（Peer Review）与投稿前严格自审（Pre-submission Audit）的执行标准。配合 `peer_review_evaluation` 与 `academic_paper_analysis` 工具使用。

---

## 一、五维同行评审角色矩阵 (Multi-Perspective Review Panel)

对任何手稿进行模拟审稿时，同时从以下 5 个正交视角展开批判性审查：

### 1. 主编视角 (Editor-in-Chief — Scope & Novelty)
- 论文解决的科学问题是否具有跨领域的广泛吸引力（Broad Interest）？
- 核心结论相比现有文献是突破性推进（Conceptual Advance），还是常规的工程增量（Incremental Extension）？
- 摘要与结论的宣称强度是否与正文提供的数据量级相匹配？

### 2. 方法学与统计审稿人 (Reviewer 1: Methodologist & Statistician)
- 实验设计是否包含合格的阳性/阴性对照？随机化与盲法是否到位？
- **统计前提核查:** 参数检验前是否验证了正态性与方差齐性？小样本是否误用了大样本渐近方法？
- **伪重复排查 (Pseudoreplication Audit):** 统计自由度（$df$）与样本量 $N$ 是否严格对应独立的生物学/实验个体，而非同一植株/动物的重复测量读数？
- **多重比较核查:** 涉及多组或多指标检验时，是否采用了 Tukey HSD、Dunnett 或 Benjamini-Hochberg FDR 校正？

### 3. 领域小同行审稿人 (Reviewer 2: Domain Specialist)
- 文献综述是否遗漏了近 3–5 年该领域的标杆性研究或经典反例？
- 实验条件（如给药浓度、环境温湿度、传感器采样率、基线模型超参数）是否符合本学科公认的生理或物理现实？
- 机制讨论是否深入本质，还是仅仅停留在表型描述？

### 4. 可复现性与数据透明性审计员 (Reviewer 3: Reproducibility Auditor)
- 数据可用性声明（Data Availability）与代码仓库链接是否真实有效？
- 关键实验步骤（试剂货号、仪器参数、预处理过滤阈值、随机种子）是否详尽到足以让第三方独立复现？
- 图表中的误差棒（SD / SEM / 95% CI）与样本量 $n$ 是否在每个图注中均有明确定义？

### 5. 魔鬼代言人 (Devil's Advocate — Counterfactual Challenger)
- **反事实压力测试:** 专门寻找核心结论的致命软肋。假设作者的核心假说是错的，现有实验数据还能用什么替代机制（混杂因素、批次效应、数据泄露、幸存者偏差）来解释？
- 需要补充哪一个最小化关键实验（Minimal Crucial Experiment / Killer Control）才能彻底堵住这一漏洞？

## 二、国际权威学术报告规范对照清单 (EQUATOR Standards)

根据手稿的研究类型，自动对照相应的国际报告指南核查必填要素：

| 研究类型 | 适用国际规范 | 审稿必查核心要素 |
| :--- | :--- | :--- |
| **随机对照试验 (RCT)** | **CONSORT** | 受试者流转图（Flow Diagram）、随机序列生成机制、分配隐藏、盲法、意向性分析（ITT） |
| **观察性研究 (队列/病例对照/横断面)** | **STROBE** | 纳排标准、暴露与结局定义、混杂因素识别与多变量调整策略、缺失数据处理、敏感性分析 |
| **系统综述与荟萃分析** | **PRISMA 2020** | 完整检索式、纳排流程图、偏倚风险评估（RoB 2 / Newcastle-Ottawa）、异质性检验（$I^2$）、发表偏倚（漏斗图/Egger's test） |
| **动物与活体生物实验** | **ARRIVE 2.0** | 样本量计算依据、动物品系/性别/日龄、饲养环境控制、随机化与盲法、伦理批件与人道终点 |
| **机器学习与预测模型** | **TRIPOD+AI** | 训练集/验证集/独立外部测试集严格物理隔离（防数据泄露）、基线模型公平调参、校准曲线与消融实验（Ablation Study） |

## 三、四大科学效度与偏倚排查框架

1. **内部效度 (Internal Validity):** 自变量与因变量之间的关联是否受到未控混杂因素（Confounding）、历史效应或仪器漂移的干扰？
2. **外部效度 (External Validity):** 样本是否具有代表性？从实验室特定条件下得出的结论能否推广到自然田间、真实临床或跨分布数据集？
3. **构念效度 (Construct Validity):** 所选用的测量指标（Proxy Metric）是否真正反映了理论上的核心概念？
4. **统计结论效度 (Statistical Conclusion Validity):** 检验功效（Power）是否足够（通常要求 $1-\beta \ge 0.80$）？阴性结果究竟是因为真的无效应，还是因为样本量太小（二类错误）？

## 四、0–100 综合质量量表与审稿结论分级

| 综合得分 | 建议决定 (Decision) | 适用情形与判定标准 |
| :---: | :--- | :--- |
| **85–100** | **Accept / Minor Revision** | 研究问题重要，实验设计严密，统计模型准确，证据完全支撑结论，仅需微调文字或图表细节。 |
| **70–84** | **Major Revision** | 核心发现具有学术潜力，但存在方法学缺口、缺少关键对照、统计检验不当或过度宣称，需补充实验或重新分析数据。 |
| **50–69** | **Reject & Resubmit** | 研究课题有一定价值，但核心实验设计存在重大漏洞或样本量严重不足，短期内无法通过简单补实验修复。 |
| **< 50** | **Reject** | 存在根本性方法学谬误、严重数据造假/幻觉引用嫌疑，或缺乏任何实质科学创新。 |

## 五、标准审稿报告输出结构

1. **Executive Summary (全文概述，1 段):** 客观总结论文的研究问题、主要方法与核心发现，并给出总体评价基调。
2. **Major Concerns (重大关切，编号列出):** 针对实验对照、统计模型、因果逻辑漏洞提出具体质疑，并明确给出**可操作的改进建议**（Actionable Remedy）。
3. **Minor Concerns (次要修改建议):** 针对图表规范、术语一致性、文献遗漏、语法润色提出逐行修改建议。
