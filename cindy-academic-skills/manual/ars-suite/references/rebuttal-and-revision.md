# 逐点答辩矩阵与修订教练指南 (Rebuttal & Revision Coach)

## 1. 逐点修改信 (Point-by-Point Response) 黄金结构

面对同行评审意见，答辩信必须条理分明，采用结构化四段式回复：

```text
[Reviewer Comment #N]
审稿人原评完整引用（保持原貌，不隐匿批评细节）

[Author Response]
1. 感谢与态度：明确表明赞同并感谢审稿人敏锐洞察。
2. 实质性修改说明：用前两句话直接交代“做了哪些改动”、“补充了哪些实验数据”。
3. 论文定位：明确标出在修改稿中的位置（例如：Section 3.2, Page 8, Lines 142-165）。
4. 补充证据：内嵌新增图表、消融实验结果或稳健性检验对比表。
```

## 2. 答辩矩阵分类与处理策略

- **AGREE_AND_REVISE (赞同并修改):** 90% 的合理批评应采纳，在正文中修改并明确致谢。
- **CLARIFY_AND_AMPLIFY (阐明并补充):** 审稿人发生误解通常说明正文表达不够清晰，需重写该小节以消除歧义。
- **POLITE_REBUTTAL (礼貌抗辩):**
  - 当审稿人提出超出本文研究边界、或存在明显事实错误的要求时，有理有据地辩驳；
  - 引用领域公认文献或补充反事实论证，说明为何不宜按其要求修改，同时在正文 Discussion 中将该点列为本研究的已知局限性。

## 3. 修订追踪与零回归保障

修改稿提交前，必须运行 `academic_integrity_audit (final_integrity_gate)`，确保新增的引用与数据没有引入新的虚构成分或逻辑回归。
