Console CLI本机生产环境

插件调用本机已安装的 console-cli。CLI 负责 OAuth 登录、Token 保存、权限和 API 自动发现。

未安装 CLI 时，请在本机终端手动执行官方安装命令： curl -fsSL https://console.tapsvc.com/cli/console-cli/install.sh | sh
打开官方地址

需要安装 Console CLI

插件需要调用本机的 Console CLI。请先在本机终端完成安装，插件不会自动执行远程安装脚本。

curl -fsSL https://console.tapsvc.com/cli/console-cli/install.sh | sh

打开官方地址
