# 测试环境

插件页面只管理测试账号：**添加账号、选择下次使用的账号、查看登录态的保存位置**。
在真实客户端正常登录，使用该账号已有的数据。页面不再要求填写项目、目录、PR、测试包、API、样本或启动方案。

首次使用时，在右侧对话里说“帮我启动客户端，我要添加测试账号”。客户端准备好后，点“添加账号”，在客户端自己的窗口完成登录。插件会自动显示应用保存的账号。选中“使用这个账号”后，让右侧对话继续测试；选中本身不会立即切换正在运行的客户端。

应用在本机持久档案中加密保存登录态，插件仅保存公开账号引用和档案位置。展开“登录态保留在哪里？”可查看路径。停止测试保留档案；过期、主动退出或授权撤销后需重新登录。现有默认约 30 天滑动续期以服务端策略为准，不承诺永久登录，不为闲置账号后台续期。

构建、启动、准备必要样本、执行验收、停止和 SSH 编排由对话调用插件工具完成；使用真实账号已有数据，不要求配置业务 API 或注入假数据。另一台电脑复用那台电脑自己的登录态，不能复制凭证文件。

本次仅改插件。当前桌面账号监管支持兼容的 Cindy 源码启动实例；不宣称任意安装包隔离启动、日常宿主直接授权、跨设备首次免密授权已实现。真实账号及真实第二台电脑仍需联调，模拟测试不能代替。操作约定见随包手册。
