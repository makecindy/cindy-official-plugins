Baguette v0.2.10 https://github.com/tddworks/baguette
Local native changes: version constant stamped from the 0.2.10 source tag (the device-set and 3D-scene fixes this plugin carried were merged upstream as tddworks/baguette#122 and #123). Source patch and rebuild instructions accompany the rebuilt Baguette and HingeControl binaries. The host binary uses whole-program LTO, size optimization, symbol stripping and ad-hoc signing. Nine unchanged portable USDZ resources are collected from the same pinned official archive at packaging time. DefaultsLookups.dylib is not bundled.
Local farm patch: remove remote font links and use existing system-font fallback.
Local Web networking patch: OSM tiles/search routed through same-origin fixed-endpoint Node proxy.
Local keyboard transport: use same-origin /clipboard; never select host or port from fragment data.
Local keyboard localization: added input errors use English fallback.
Local keyboard patch: serialize paste/copy with keys; suppress only adjacent identical pending paste; report queue overflow.
Local Web security patches: toolbar labels rendered as text; CSS selector fallback uses hexadecimal escaping.
Local Web orientation patch: opening a view restores its per-device bezel pose; only an unknown pose is seeded from the existing describe_ui socket message. App orientation cannot override a known viewer pose, and no implicit rotation is sent. Independent bootstrap reads run concurrently.

Local Web gesture overlay patch: wheel pan/pinch indicators project both actual touch contacts into view coordinates, keeping parallel pans parallel. Version 0.2.59 bounds wheel-move contacts before dispatch and display, matching native backend clipping at screen edges; no upstream version, binary, permission or network change.
Local Web native contact patch: flat screens opt into host trackpad input; Chromium TouchEvents preserve independent contact positions and release on cancellation. Version 0.2.60 restores the existing orientation-aware single-touch edge hint through move/release and clears it at pair/cancel boundaries. Safari retains its existing gesture stream. No upstream version change.
Local Web patch: the Defaults card toggle is removed; the plugin proxy blocks its routes. See vendor-web.patch and VENDOR-REVIEW.md.

0.1.2: Official logo resized to 512 × 512 PNG for Cindy’s 512 KiB icon limit; artwork unchanged.

0.1.3 modification: bundled Web/stream-session.js reconnects after an unexpected WebSocket close, releases old decoder/timers, and cancels reconnect on deliberate stop. Native Baguette binary remains unchanged.

0.1.4 modification: bundled Web/baguette/parts/keyboard.js routes user clipboard actions through a loopback bridge scoped to the private device set, with exact Origin and random capability checks and visible failure feedback. Native binary unchanged.

0.1.6 itemized modifications: native/keyboard.m adapts the CoreSimulator resolution and SimulatorKit HID protocol from Baguette v0.1.98 (Apache-2.0), adds completion acknowledgements, exclusive device lock and release-only recovery; compiled as native/keyboard (Apple Silicon, ad-hoc signed). Web/baguette/parts/keyboard.js routes all keyboard/text input through the acknowledged adapter, suppresses repeats and serializes key bursts. Web/baguette/parts/bezel.js, Web/baguette/carplay/carplay-frame.js and Web/sim-native.html replace crosshair with default cursor. Original Baguette binary remains unchanged.

0.1.24: upgraded to Baguette v0.2.7 (official tag and release archive above); native/web patches regenerated with context; idb MIT notice added for HingeControl's Frontmost.m; DefaultsLookups.dylib excluded. The plugin is renamed iOS Simulator and its icon is replaced with Cindy's own; the Baguette logo is no longer shipped.
0.1.24 (2026-10-21): upgraded to Baguette v0.2.8; the guest hinge-read patch is retired (merged upstream) and replaced by the device-set and 3D-scene patches above; Web gains upstream's unmodified sim-notify.js. Then upgraded to v0.2.10 once both patches were merged upstream; only the version stamp remains.
