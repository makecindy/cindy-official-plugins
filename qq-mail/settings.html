The authorization code is encrypted and stored locally by Cindy

In QQ Mail on the web, open "Settings → Account and Security → Security Settings", enable IMAP/SMTP, and generate an authorization code. Do not enter your QQ password here.

The authorization code is never included in Agent parameters or plugin main.js. Cindy provides it to the plugin Worker only while a mail request is running. IMAP/SMTP connections close immediately after each operation.
