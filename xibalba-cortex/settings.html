Applies to supported main conversations while enabled. Sends user and assistant text to the selected Cortex profile. Cortex redacts likely secrets. Tool arguments, attachments, reasoning, and background conversations are not captured. Capture is best effort; text is not queued on disk or retried automatically.

Opt-in local capture reads this database without modifying it, including saved tool calls/results, questions, plans and background sessions. It catches up after restart and retries with durable checkpoints. Includes persisted artifact references; excludes reasoning, arbitrary file contents and data Cindy did not save. Requires local Cortex and recording enabled.

Snapshot explicit attachments and eligible task file references, up to 50 MiB per file. Originals are saved as bytes; binary attachments are not secret-redacted. Missing, changed, unsupported and oversized references receive status manifests. No directory crawling.
