Third-Party Notices for the Cindy TapTap Maker plugin
=====================================================

This plugin ships a vendored copy of the official @taptap/maker npm package
(version 0.0.32, MIT, https://github.com/taptap/instant-games-open-mcp). Its
MIT license text is reproduced in vendor/taptap-maker/LICENSE, which covers
TapTap's own code only.

vendor/taptap-maker/dist/maker.js is an esbuild bundle produced upstream. It
additionally embeds the open-source packages listed below, and was built
without preserving their legal comments, so their notices do not appear in the
bundle itself. They are reproduced here in full instead.

Provenance of this list
-----------------------
The package list was derived from the module paths that esbuild retained as
comments in the shipped bundle (grep for "^// node_modules/" in maker.js), so
it reflects the packages actually present in the artifact.

Exact dependency versions are not recorded in the vendored artifact, and the
published npm tarball does not include an upstream lockfile. Version numbers
are therefore deliberately omitted rather than inferred from repository
state. Where a package changed license across major versions, the version
present in the bundle was identified from its file layout: the bundle contains
isexe/index.js, isexe/mode.js and isexe/windows.js, which is the isexe 2.x
layout (ISC) rather than 3.x+ (BlueOak-1.0.0).
