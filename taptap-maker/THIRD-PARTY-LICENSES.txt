isarray

# isarray

`Array#isArray` for older browsers.

[![build status](https://secure.travis-ci.org/juliangruber/isarray.svg)](http://travis-ci.org/juliangruber/isarray)
[![downloads](https://img.shields.io/npm/dm/isarray.svg)](https://www.npmjs.org/package/isarray)

[![browser support](https://ci.testling.com/juliangruber/isarray.png)
](https://ci.testling.com/juliangruber/isarray)

## Usage

```js
var isArray = require('isarray');

console.log(isArray([])); // => true
console.log(isArray({})); // => false
```

## Installation

With [npm](http://npmjs.org) do

```bash
$ npm install isarray
```

Then bundle for the browser with
[browserify](https://github.com/substack/browserify).

With [component](http://component.io) do

```bash
$ component install juliangruber/isarray
```

Third-Party Notices for the Cindy TapTap Maker plugin
=====================================================

This plugin ships a vendored copy of the official @taptap/maker npm package
(version 0.0.39, MIT, https://github.com/taptap/instant-games-open-mcp). Its
MIT license text is reproduced in vendor/taptap-maker/LICENSE, which covers
TapTap's own code only.
The bundle retains ten compatibility patch groups: preserve the remote
executed execution state (original commit ff54f59), return structured
not_executed state for BLACKLISTED tool-call rejections, and check access per
request rather than caching it at startup, and retain the BLACKLISTED reason
in tools/list response metadata, and reject symlinked user-Skill write roots
before installation, restrict MAC-expiry replay to explicitly not-executed
requests, and isolate Cindy console launcher identity by distribution and entry.
The execution-state patch also covers the 0.0.37 state aggregator and conflicts.
The eighth patch hides model settings and disallows custom API configuration
in Cindy distribution, with Server-only recognition and no provider fallback.
The ninth patch preserves uncertain cloud Git commit outcomes and truthful recovery
guidance, and recognizes old and new cloud-workspace blocking messages.
The tenth patch retains uncertain canvas generation and recognition requests,
pauses automatic recovery at its wait limit, and supports stopping subsequent
015 workflow steps during preparation and recovery waits.
Runtime 0.0.39 also removes the upstream ChatGPT recognition fallback; no new
bundled dependency names were added relative to 0.0.37.
The paired repository READMEs
document this complete patch list for future upgrades.

vendor/taptap-maker/dist/maker.js is an esbuild bundle produced upstream. It
additionally embeds the open-source packages listed below and only retains some
upstream legal comments. This file supplies the full license texts for the
bundled dependencies.

Provenance of this list
-----------------------
The package list was derived from the module paths that esbuild retained as
comments in the shipped bundle (grep for "^// node_modules/" in maker.js), so
it reflects the packages actually present in the artifact.

Exact dependency versions are not recorded in the vendored artifact, and the
published npm tarball does not include an upstream lockfile. Version numbers
are therefore deliberately omitted rather than inferred from repository
state. Where a package changed license across major versions, the version
present in the bundle was identified from its file layout: the bundle contains
isexe/index.js, isexe/mode.js and isexe/windows.js, which is the isexe 2.x
layout (ISC) rather than 3.x+ (BlueOak-1.0.0).
