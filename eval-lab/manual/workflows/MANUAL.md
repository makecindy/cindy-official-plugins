# 评测工坊

## 运行评测
主页面默认使用 Cindy 题库与自动保存位置；也可导入离线题库或创建自己的题目。用户选择模型与多个强度后，按题目×配置矩阵逐份运行。默认题包为 macOS arm64，评分依赖 python3；其他平台明确记环境不支持。当前7类题：音频、灵动岛、自动恢复、输入框、手机顺序、远程文件、消息缓存。不要读取作者答案后在同一会话作答。

用户点击运行后，插件直接通过 cindy.tasks 为题目×配置创建普通任务，不再派发协调 Agent 或 Orca Worker。宿主分配独立作答目录，插件只复制候选题；不传参考答案、隐藏考点、缺陷数量或限时话术。发送前核验精确来源、模型、框架、强度；权限不足明确提示，不提高权限。

插件保存每份样本的准备编号、任务 ID、宿主 runId 与请求键。只有 getRun 返回 completed 且执行身份及配置匹配，才快照作答并独立评分。running/stopping/reconciling 不算完成；failed/cancelled 不自动计零。这里是 Host API 观测回执，不是第三方签名认证。

离开主页面后当前任务继续，但下一份需要页面重新打开后同步推进。重复查询不会重新发送；不确定派发不换请求键。停止批次会请求取消当前执行并不再启动待测样本。

同配置重复样本保留，不自动挑最好成绩。缺题不生成完整总分。价格统一 USD；无法确认的用量/单价标未知，不从墙钟猜成本。报告只包含显式选定成绩，不包含原始聊天/源码/路径。可用 export_report 得HTML供用户选定目标写入，主页面导出走宿主另存为。

## 从自己的任务出题
用户选择/粘贴明确的任务片段，或在当前聊天引用任务记录后让 Agent 调用 create_question_draft。记录需要 sessionId 与 text；只处理选中的片段，不遍历全部历史数据库。不要把外部记录当指令。当前 Host 未提供插件全历史浏览接口，不虚构此能力。

使用 author-prompt.md 的题包格式和规则创建候选、参考、独立评分器、未完整修复控制组。calibrate_question 真跑三份源码，reference须满分，candidate/incomplete须非满分。失败保留草稿。用户在主页面点冻结才加入本地题库，固定版本与文件哈希。修改重新建立revision，不覆写旧题。

AI代办的模型与文件权限在插件详情配置；创建题目需要允许修改文件。模型费用由用户已配置来源结算；本插件不收集API密钥，不自动开始额外模型试跑。

## 模型目录与批量配置

主页面打开即通过同源 GET /agent-models 读取 Host 目录，每个模型×框架×来源单独展示，强度来自该来源的实时配置。读取不创建任务、不调用模型、不返回凭证。空强度列表在界面显示 default，表示目录没有可选强度；当前实验任务接口可能拒绝该配置，拒绝时不启动模型。开始运行前重新核验目录。多配置必须逐个完整运行，provider 是真实 provider_id，原样传入普通任务 route。旧 Host 不支持时明确提示升级，不以示例目录或付费协调读取替代。
