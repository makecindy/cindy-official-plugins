# DeepSeek Harness

Install DeepSeek Harness in **Plugins → Marketplace** on Cindy 0.1.143 or later. Open the plugin settings to check or install `dsh` and configure your DeepSeek API key. Select DeepSeek Harness in the model picker to run a task. Remote execution and sharing require a host with plugin engine sharing support.

[Original source and CLI documentation](https://github.com/makecindy/cindy-dsh-plugin/tree/5914993db61302cb7392abec5d08cc26161b515c)
