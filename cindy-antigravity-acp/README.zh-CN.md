# Antigravity

在 Cindy 0.1.143 或更高版本的「插件」市场安装 Antigravity。打开插件设置检测或安装 `agy` 并配置默认 Google 账号，也可以在「设置 → 模型供应商 → Antigravity」里添加多个 Google 账号参与混用与负载分配，再从模型选择器选择 Antigravity 运行任务。远程调用和分享需要支持插件引擎分享的宿主。

[上游源码与 CLI 说明](https://github.com/makecindy/cindy-antigravity-plugin/tree/768ffa8d26f2e5ea9f0e6e3476d0c49dc1b8681d)
