# Antigravity

在支持的 Cindy 版本上，Google 要求验证账号时，任务内会自动展开扫码卡。扫码或点开链接即可前往 Google 官方页面；账号检查通过后继续原对话。

在 Cindy 0.1.143 或更高版本的「插件」市场安装 Antigravity。打开插件设置检测或安装 `agy`，配置自己的 Google 账号，再从模型选择器选择 Antigravity 运行任务。远程调用和分享需要支持插件引擎分享的宿主。

[上游源码与 CLI 说明](https://github.com/makecindy/cindy-antigravity-plugin/tree/768ffa8d26f2e5ea9f0e6e3476d0c49dc1b8681d)
