# Antigravity

在 Cindy 0.1.148 或更高版本的「插件」市场安装 Antigravity。打开插件设置检测或安装 `agy`；账号统一在「设置 → 模型供应商 → Antigravity」里添加和管理，可以登录多个 Google 账号、查看各自的用量并在账号之间分配任务。然后从模型选择器选择 Antigravity 运行任务。远程调用和分享需要支持插件引擎分享的宿主。

[上游源码与 CLI 说明](https://github.com/makecindy/cindy-antigravity-plugin/tree/768ffa8d26f2e5ea9f0e6e3476d0c49dc1b8681d)
