# Antigravity

On compatible Cindy hosts, a Google account verification error opens a scan card in the task. The link opens Google’s own page. The plugin compares the Google account recorded by the original ACP process with the account in each verification check. Switching accounts or a missing identity keeps a pending task waiting. Only a matching account can resume the native conversation. The plugin keeps the comparison local and removes its temporary diagnostics when the task ends.

Install Antigravity in **Plugins → Marketplace** on Cindy 0.1.148 or later. Open the plugin settings to check or install `agy`. Accounts are added and managed in **Settings → Model Providers → Antigravity**: sign in to several Google accounts, see each one’s usage and share tasks between them. Then select Antigravity in the model picker to run a task; direct models are listed ahead of Antigravity's built-in Orchestrator modes (which do not expose reasoning levels). Remote execution and sharing require a host with plugin engine sharing support. In those tasks Antigravity can ask questions and show steps, and with agy 1.5.18 or later also start subagents and set timers; its own file, command, browser and image tools stay off there, and Cindy's tools on the task's computer take their place. Those tasks also take the instructions Cindy passes for the whole session (ACP `systemPrompt`, such as your custom instructions on Cindy versions that send them) and add them to the agent's instructions; tasks on this computer do not take them yet.
