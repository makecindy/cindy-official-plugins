# Antigravity

Install Antigravity in **Plugins → Marketplace** on Cindy 0.1.143 or later. Open the plugin settings to check or install `agy` and configure your Google account. Select Antigravity in the model picker to run a task. Remote execution and sharing require a host with plugin engine sharing support.

[Original source and CLI documentation](https://github.com/makecindy/cindy-antigravity-plugin/tree/768ffa8d26f2e5ea9f0e6e3476d0c49dc1b8681d)
