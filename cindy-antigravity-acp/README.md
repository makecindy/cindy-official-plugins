# Antigravity

Install Antigravity in **Plugins → Marketplace** on Cindy 0.1.148 or later. Open the plugin settings to check or install `agy`. Accounts are added and managed in **Settings → Model Providers → Antigravity**: sign in to several Google accounts, see each one’s usage and share tasks between them. Then select Antigravity in the model picker to run a task. Remote execution and sharing require a host with plugin engine sharing support.
