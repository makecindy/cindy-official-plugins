# GitHub 可选 CI 恢复

GitHub 贡献者可能有权限推送自己的 PR 分支，却没有权限重跑失败的 Actions 任务。
反复出现的故障，根本仍应通过提高测试和 CI 稳定性解决。GitHub 插件另外提供有限的
恢复途径：确认是临时故障，且正常重跑明确因权限被拒后，才考虑重推。

在 PR 卡片右上角设置中，可以开启
**CI 无重跑权限时重推重试**。默认关闭，存量用户没有字段时也关闭。偏好保存在本机
当前插件用户的设置中，后续所有仓库和 PR 的实际跟进轮次共用，不同步到其他电脑。
可随时从任意 PR 卡片关闭。此偏好不会自行启动自动跟进，也不授予合并权限。

现有 PR Skill 在新建跟进、每个实际后台轮次，以及 amend 和 push 前重新通过
`pr_follow_settings` 读取当前偏好。旧提示词或卡片返回不能作为长期重写授权。
字段缺失、关闭或读取失败都禁止仅为 CI 重试改写提交；正常且已授权的修复仍可继续。
所有卡片复用主逻辑页现有的串行队列，按显示的目标值设置开关，不对较新的全局值
再次取反。插件账号设置页不再提供 PR 偏好控件，也不读写该偏好；旧偏好广播被忽略，
专用握手及第二入口已移除。写入结果未知时先回读核对，不盲目重放。
读取失败或存储格式无效时，卡片显示未知状态，不提供开关/模型选项，不把它画成关闭。
“刷新 PR 设置”只读当前值。每次偏好操作后都回读，包括保存已完成但响应丢失的情况；
不再把未确认的写入说成“没有保存”。回读仍失败则保持未知，不产生新的重推许可。

恢复要求 PR 仍 open，已诊断为与本 PR 改动无关的临时 CI、安装或基础设施故障，且
正常 rerun 明确被权限拒绝。需要批准的工作流、保护规则阻断、确定性故障及结果未知
不适用。必须确认 head 是本任务可独占改写的分支，具有写权限，没有 WIP、重写禁令、
未知或他人的提交。优先处理已经需要的真实修复，能正常合并为一次推送时不额外重写。

全部条件满足后，Agent 才能在保留提交意图、代码树、父提交、作者及仓库 DCO 要求的
前提下 amend。这会改变提交 SHA。还需保留签名来源证明：原 head 已签名时，
占用额度前必须验证原签名，并确认现有自动
签名配置及合法密钥可用；否则停止，包括仅曾用单次 `git commit -S`、未配置自动签名
的情况。重写后再次验签；签名缺失、无效或未知均不推送。明确目标的推送使用
`--force-with-lease=refs/heads/<branch>:<先核验的远端SHA>`。远端出现插入提交即终止，
不能刷新 lease 后盲推。随后核对新 SHA 确实进入原 PR，以及 CI 是否真正启动；启动
不代表通过。

**本机每个 PR 累计最多两次 CI-only 重推，同一故障最多一次。** 达到总上限后，
即使诊断不同也停止并报告，不再 amend/push。每次 amend 前，既有 gate 用不可变 PR
`node_id` 排他创建两个固定持久名额之一，记录稳定诊断（workflow 文件、job 名称、
失败 step、归一化根因）。两个额度命令都必须带已核验 ID 和
`--ci-retry-failure <诊断.json>`。诊断不得包含 SHA、run/job ID、attempt、时间戳或临时
路径；换 SHA、重启、改名/转移、重置观察状态及中途退出都不能让同一故障再试。
不同故障需重新核验日志、rerun 权限拒绝及全部条件后，才能使用剩余名额。
gate 会归一化大小写和空白，但不代替 Agent 判断根因；无法区分时停止，不编造新诊断。
旧开发版缺少诊断的记录须先核对原执行结果，不能丢弃。记录不退款、不随 trace 清理；
不得删文件、换目录或重置额度。结果未知时先核对远端，不能盲推。回执保存在用户
持久数据目录，与可清理的观察/trace 缓存分开。gate 在解码/校验前排他复制旧缓存回执，
不覆盖持久记录、不删原件；会把当前 PR 所有旧诊断回执计入两个名额，即使查询的
是另一个故障。status 查询也可能执行此迁移；旧记录超过两次或证据损坏/不明时停止。
缺诊断或格式损坏的证据在清缓存后仍保守拒绝。PR node ID 沿用核实的 opaque 原值，
也支持旧 base64 格式。
清空或更换缓存不会恢复
已迁移的额度。升级前已删除的未知证据不能重建，不代表允许重试。各平台目录见
Skill 引用，不得通过更换数据根环境变量恢复次数。

插件沙箱不直接运行 Git，也不能机械判定日志故障及分支归属。这些事实核验和 Git
操作仍由既有任务 Agent 工作流及任务授权承担；gate 确定性限制的是次数，不是这些
事实判断。不新增平台 scope、凭证、宿主 runtime 或服务端改动。开关不授权空提交、
裸 force、合并、auto-merge、队列操作、主干直推或改权限。
