# PR 跟进入口回执验证

当前候选插件：`cindy-github` 1.5.36；基线：`2143701`；环境：Windows、Node.js 22.22.3。

## 受影响行为

`pr_card`、`pr_follow_settings` 的成功回执，以及需要 Agent 交接的发 PR/发草稿/跟进按钮事件，
现在携带 `follow_workflow`。它标明包内 `skills/pr/SKILL.md` 和
`skills/pr/scripts/pr-heartbeat-gate.mjs`，要求从当前会话可用 Skills 中读取同一
namespace 插件的实际安装入口，避免把包内相对路径误当作业务仓库路径。

回执明确区分未声明 Manual 与随包 Skill 不可用：前者继续读取随包说明和检查器；
后者报告具体缺口，不自行编写、复制或内联实现跟进脚本。四语言同步。

`ghost_manual` 是宿主工具，本次不改变其失败响应；恢复入口由插件回执提供。
本次没有新增工具、宿主权限、网络目标或自动化，不改变跟进开关和合并授权。

基线 #352 已提供卡片直接管理跟进的能力；支持该能力的宿主返回 `follow_state`，
Agent 不再创建重复调度。旧宿主的 Agent 交接仍携带本 PR 的读取入口。
