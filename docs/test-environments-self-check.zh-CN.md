## 修复的问题

| 路径 | 原问题及影响 | 当前处理 |
| --- | --- | --- |
| 停止与动作 | 停止请求写入后仍可发起新命令；注册命令时并发停止可能漏停新任务 | 动作前、加锁后检查取消；注册后补停；取消后拒绝账号切换 |
| 本机请求并发 | 较早发出的 status 回包可覆盖新动作的 unknown 状态 | 同一 runId 串行处理；失联仍先查询，不盲目重试；按进程身份恢复异常退出留下的锁 |
| SSH 回执 | 逐段转字符串会损坏被分割的中文；进程已启动后报错被归为未执行 | 限制总字节，拼接后统一 UTF-8 解码；进程启动后的异常保留 unknown |
| 公共工具错误 | remote 经公共 Worker 调用时，缺少明确执行结论的异常可能被标为未执行 | remote/停止等写操作默认 unknown；保留明确回执的执行状态，CLI 同样保留 |
| Git 检出 | 共用 FETCH_HEAD 影响 B 原仓库，并发拉取可能互相覆盖 | 每次运行使用自己的 ref，禁写 FETCH_HEAD；仍严格核对指定 SHA |
| 证据目录 | 后续文件校验失败时先前文件已落盘；重复收集可能混入旧截图 | 完整验证名称、重复项、编码、大小和摘要后暂存，整套完成再移入独立目录 |
| 证据读取 | 文件检查后增长会突破读取上限；短读取可能填入无效字节 | 固定长度分段读取，使用实际读取长度，保留日志截断说明 |
| 账号监管 | 在线验证后的身份/登录变化仍显示旧账号；远程被控配置变化未复核 | 使用最新快照展示账号与登录状态，配置变化时取消 ready |
| 进程归属 | 监管进程退出后，PID 被复用仍可能显示旧 ready | 状态带进程启动身份，身份不符返回 unknown 并撤销旧联网校验 |
| 远端账号发现 | 本次新登录的账号虽已记录，A 却拿不到其目录 ID 来切换 | status 返回本次账号的白名单引用字段，不返回 sessions 或凭证 |
