# 模拟器键盘与高级工具验证

日期：2026-10-31。插件：`baguette-simulator` 0.3.26。
源码：`dash/simulator-keyboard-controls`，基于 `8f4dd3d` 的本次改动。

## 行为

- 键盘菜单显示下一步动作：「使用手机键盘」或「使用电脑键盘」。不增加开关图形或状态标记。
- 高级工具展开后菜单显示「关闭高级工具」，原位收起，不重载画面连接或录屏。顶部不增加标题或按钮栏。
- 手动「释放所有按键」仅在高级工具展开后的「更多」菜单出现，作为故障备用。
- 控制器失焦、页面隐藏时发出已有释放通知；安卓补齐通知及隐藏事件处理，丢弃待发输入、释放触点。iOS 原有按键配对释放及错误清理保持不变。
